# 🧠 Parkinson’s Disease Prediction Model

*A.k.a. "Doctor Python with X-Ray Glasses"*

Welcome to the land where math meets medicine, and PCA + RFE join forces like the Avengers to fight uncertainty. This project is a **machine learning model** that predicts Parkinson’s Disease using voice features, clever feature selection, and a dash of computational wizardry.

---

## ✨ Features We Care About (a.k.a. the Chosen Ones)

We started with a lot of features but, thanks to **PCA (Principal Component Analysis)** and **RFE (Recursive Feature Elimination)**, only the strongest survived.
Our top contestants in this voice-based *America’s Next Top Feature* include:

* 🎤 `PPE` – Pitch Period Entropy (no, not Pepsi)
* 🎶 `meanAutoCorrHarmonicity` – The "how musical is your voice" factor
* 🫨 `locAbsJitter` – Tiny shakes in your voice
* ✨ `locShimmer` – Sparkles… but for sound waves
* 🎚️ `meanNoiseToHarmHarmonicity` – How much noise crashes your vocal party
* 🧩 `tqwt_entropy_shannon_dec_17` – Because one entropy wasn’t enough
* 🧮 `tqwt_entropy_log_dec_27`
* 🧮 `tqwt_entropy_log_dec_32`
* 🧮 `tqwt_entropy_log_dec_34`
* 🧩 `tqwt_entropy_shannon_dec_18`

Basically, it’s like your voice went through a **CSI lab test**.
